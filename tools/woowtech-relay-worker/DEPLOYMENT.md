The Worker forwards plaintext contents within the trusted service, with HTTPS/WSS transport encryption; it does not implement Paseo's end-to-end encryption. It supports multiple accounts with one phone each. Control operations are serialized per tenant; request bodies are bounded; pending requests are scoped to their WebSocket. Website logout does not revoke phone pairing. Disabling an Odoo account does not automatically disconnect an already-paired phone. Limits are request/concurrency based, not monthly bandwidth quotas. The interface currently uses Traditional Chinese only. The old Go gateway remains in the original Mac workspace; this deployment source is in the Pi workspace.
