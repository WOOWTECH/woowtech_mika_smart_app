# 50 個實機對話回歸案例

這個程式透過已安裝 App 的任務 API 建立真實對話、呼叫目前設定的模型與工具，會消耗模型額度。不是 mock，也不是單元測試。案例包含手機操作、沙箱產出、測試記憶新增／刪除、追問、取消、插話與重送防重；不傳訊給他人、不付款、不安裝 APK。

先取得手機使用授權、確認 App 的電腦連線已開啟，以及原有任務已結束。保持手機供測試使用，避免同時操作。語音收音與安裝安全防護不包含在這 50 個案例中。

```sh
export ANDROID_SERIAL='裝置序號'
export ADB="$HOME/Library/Android/sdk/platform-tools/adb"
export QA50_OUTPUT="$HOME/qa50-evidence/一次新的測試目錄"
"$ADB" -s "$ANDROID_SERIAL" forward tcp:18765 tcp:8765
python3 tools/qa50/run.py 1 50
```

`QA50_BASE_URL` 可覆寫預設 `http://127.0.0.1:18765/api/v1`。`QA50_CONFIG` 可覆寫手機設定檔路徑；預設讀取渥屋助理外部 files 目錄的 `mcp-usb.json`。驗證權杖只載入記憶體，不寫入測試收據；請勿把完整設定檔或 HTTP headers 放入報告。

## 執行與判讀

- 每案依序執行；案例 10 在同一對話加入第二輪。
- 每個 request_id 先落盤，180 秒測試截止後要求取消；這是測試程式的時限，不代表 App 已內建整體預算。
- 預期追問以指定測試答案回覆；意外追問或手機確認會取消並保留證據，不代替使用者核准。
- 48 驗證取消、49 驗證插話、50 以同一 request_id 重送。48 的預期終態是 cancelled。
- 已完成檔案會略過；存在未完成收據會停止，必須先核對 App 任務狀態，避免重複執行。
- 成功回傳 `done` 只代表任務結束。需人工核對答案、ADB 讀值、產出檔案，以及取消／插話收據，才能判定通過。
- 記憶案例 39–41 必須一起完成；若中途中止，確認只清除「QA50測試專案」的測試記憶。
- 保留對話供檢查，輸出收據存於本機私人目錄，勿提交使用者資料。

案例清單與期待結果見 `cases.json`。單次通過不能外推至其他手機、模型、語系、網路或背景狀態。
