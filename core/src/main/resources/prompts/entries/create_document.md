Create a local HTML, PDF or CSV document from known source content. Ask if the source or table selection is ambiguous. Use document.title and document.sections: heading(text, level), paragraph(text), bulletList/orderedList(items), table(columns, rows). Text is literal, not HTML. CSV exports one table; select tableIndex when there are several. Formula-like CSV fields gain an apostrophe; disclose this. After success, call share_file with the returned path to save a previewable attachment. This opens the file tools; it does not send files to anyone or publish a website.
