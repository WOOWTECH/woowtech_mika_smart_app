# Google Play Data safety 填答依據：渥屋助理商店版

更新：2026-11-12。適用套件 `io.woowtech.assistant`。這是供 Play Console 逐題核對的工作表，**尚未提交的答案**；Console 顯示的題目與最終 AAB 應優先。

Google 將從 App 傳出手機的資料視為「收集」，即使接收方是第三方 SDK 或使用者選擇的供應商。公開網頁瀏覽器的網站資料有特定例外；短暫處理、使用者主動分享、服務供應商等例外須依各題定義判斷，不能直接寫成「完全不收集」。[Google Data safety 說明](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)。

## 跨欄位檢查

- **資料有傳出裝置：是。** 對話、附件、語音、MCP、檢舉和選用診斷如上；多數由使用者啟用，AI 對話本身需要模型服務。
- **傳輸加密：** 商店版模型只連官方 HTTPS API；手機以外的 MCP 與診斷接收端也要求 HTTPS。Android 網路安全設定禁止其他明文連線，只允許同機 `localhost` 與 `127.0.0.1`。填 Console「所有資料傳輸都加密」前，還要核對 Android 語音服務、第三方登入及最終 AAB。
- **模型範圍：** 商店版提供 OpenAI、Anthropic、Gemini 官方 API 及 ChatGPT 帳號登入；既有自訂或聚合端點設定會保留供辨識與移除，但不能再用於模型或語音請求。供應商安全措施不能代替 App 的檢舉營運與政策審查。
- **刪除：** 使用者能刪除本機對話、記憶、技能及已收且有刪除回執的檢舉；無回執的檢舉或外部模型／網站持有的資料，依政策上的聯絡與第三方程序處理。不可宣稱在 App 刪除本機資料就能刪除第三方資料。
- **分享：** 模型、MCP、語音供應商和使用者指定的診斷接收者與渥屋科技不同。是否套用使用者主動轉移或服務供應商例外，需依 Console 現場題目逐項核對；不應直接回答「沒有分享」。
- **廣告／帳號：** 此版未發現廣告 SDK；App 不建立渥屋科技帳號，第三方模型帳號由第三方管理。正式填答須以最終依賴與實際登入頁為準。
- **SDK：** 此版已將跨 App OCR 專用的 ML Kit 依賴移出商店變體，並移出沙箱執行檔與根檔案系統。最終 AAB 仍需掃描依賴、manifest、assets 和 native libs，以確認沒有遺留的第三方資料流。[Google ML Kit 資料揭露說明](https://developers.google.com/ml-kit/android-data-disclosure)。
