| 項目 | 操作與通過標準 | 目前狀態 |
| --- | --- | --- |
| 安裝來源與簽章 | 從內測連結安裝，核對版本、套件、Play 分發憑證與首次啟動；保留安裝畫面與版本證據。 | 待 Play 內測 |
| 首次設定 | 英文與繁中歡迎頁可見；只提供 ChatGPT 與三家官方 API；未設定模型時不能誤進可對話狀態。 | AAB 衍生版已通過；待 Play 重驗 |
| 官方模型對話 | 用審查專用官方 API Key 和模型設定、測試並儲存；新對話要求只答 `PLAY_OK`，確認回覆與用量紀錄。 | POCO ChatGPT 曾成功；官方 Key 與 Play 版待驗 |
| 登入與前景服務 | 啟動 ChatGPT 登入時能見到瀏覽器和進度通知；取消後服務結束。另送出 AI 任務確認通知與停止操作。 | AAB 衍生版登入啟動／取消已通過；Play 版待驗 |
| 語音與附件 | 真人對著實機說測試句，確認轉寫保留於輸入框；用系統選擇器加入並移除測試照片與文件，送出時確認模型實際收到。 | Debug 版部分通過；Play 版與附件送出待驗 |
| 瀏覽器 | 開啟公開 HTTPS 網頁及 App 內隱私頁，切回對話並確認頁面仍可用。 | Debug 版通過；Play 版待驗 |
| 記憶與技能 | 新增測試記憶／技能，跨對話查回或使用，再逐筆刪除；確認清理後不再顯示。 | Debug 版通過；Play 版待驗 |
| 外部 MCP | 新增唯讀 HTTPS 測試伺服器，列出工具，限制允許清單，讓模型實際呼叫允許工具並拒絕未允許工具；刪除連線。 | Debug 版 HA 唯讀鏈路通過；Play 版待驗 |
| AI 回覆檢舉與刪除 | 對測試回覆送出標記為測試的檢舉，確認伺服器回執、重開 App 後仍顯示、再刪除測試檢舉。 | 正式端＋Debug 版通過；Play 版待驗 |
| 版面與能力界線 | 直橫向側欄、深淺色、截圖／錄影可用；確認商店版沒有跨 App 操作、手機遠端連接與沙箱執行入口。 | Debug 版與程式碼已檢查部分；Play 版待驗 |
| 穩定性 | 每段測試記錄時間、裝置、版本、結果與必要截圖；檢查崩潰或 ANR，清除測試資料。 | 待 Play 內測 |

內測通過後，用該版本補拍對話、瀏覽器、記憶等真實商店截圖，核對 Data safety、隱私政策、審查員指引與實際網路行為一致，再提交正式審查。POCO 的 Debug 版資料不得為了安裝 Play 版直接解除安裝清除。
