### 本機資料

渥屋助理會在您的裝置保存對話紀錄、個人記憶、選擇的附件、模型與 MCP 伺服器設定，以及瀏覽器的歷史、書籤、網站設定與 Cookie。記憶及保存的模型與 MCP 憑證使用裝置端加密。App 的 Android 備份功能已停用。【依最終版核對各類資料的儲存、加密與移除方式。】

您可以在 App 內刪除個別對話、管理記憶與技能、移除設定的 MCP 伺服器。刪除裝置上的資料不會自動刪除已傳給外部模型服務、語音服務、MCP 伺服器或網站的資料；請依各服務的規則處理。

### 模型服務與附件

您可自行選擇支援的模型服務，並使用自己的帳號或 API Key。您送出請求時，App 會將提示詞和完成任務所需的相關對話內容傳給所選模型服務。若您選擇附件、使用記憶或工具，相關內容也可能包含在模型請求中。所選服務對資料的保存與刪除依該服務的政策及條款處理。

### 語音與瀏覽器

使用語音輸入時，App 會在需要錄音時要求麥克風權限。依您的設定及裝置，語音可能由 Android 語音辨識服務處理，或傳給您選擇的語音服務；辨識結果可成為您送出的文字。內建瀏覽器開啟網站時，網站會收到正常網路請求，並可能依其政策使用 Cookie 或收集資料。

### 外部 MCP 伺服器

您可以自行設定外部 MCP 伺服器及可用工具。當您執行任務並使用相關工具時，工具參數、您提供的內容或模型選擇傳送的上下文可能傳給該伺服器；伺服器回傳的內容也可能傳給所選模型，以便產生回答。實際接收者、處理及保存方式取決於您設定的伺服器與工具。

外部 MCP 預設要求 HTTPS，使用者可依設定啟用本機或私人網路 HTTP。自訂模型端點也可使用 HTTP，對非本機或私人網路位址會顯示提示，但不會阻止。使用未加密連線時，相關傳輸不具 HTTPS 的加密保護。【核對最終版允許的傳輸方式與使用者提示。】

### AI 回覆檢舉

如果您主動檢舉 AI 回覆，App 會在裝置上保存您選擇的回覆、檢舉原因、選填說明、識別碼及送達狀態，並將必要資料傳給渥屋科技的檢舉收件服務，以供處理檢舉。【在正式服務完成部署與驗證後，填入實際處理目的、收件服務與處理人員、儲存地點、來源 IP／日誌處理、保存期限、本機與伺服器的刪除請求方法、失敗重試及日誌／備份規則；不得把程式設計值當成已驗證的營運承諾。現有程式未確認提供使用者操作的檢舉刪除介面。】

### 保存、刪除與聯絡

裝置端資料依您使用的刪除功能及裝置設定處理。【營運者確認各類本機與伺服器資料的保存期限、刪除方式、合法保留例外與請求回覆時間，並在此填入。】如果 App 允許建立渥屋助理帳號，另須確認並提供 App 內與公開網頁的帳號及相關資料刪除請求途徑；外部模型供應商的帳號由該供應商管理。

如需詢問本政策或提出資料處理請求，請聯絡上述隱私聯絡方式。【確認實際受理程序。】

1. 核對最終 AAB 的功能、權限及第三方資料流，確認本政策未描述已移除的電腦連接或尚不存在的功能。
2. 確認營運者、聯絡、正式檢舉服務、保留及刪除事實；完成各方括號並由負責人審閱。
3. 依最終內容提供適用語言版本，發布於可公開且免登入讀取的政策頁；驗證網站及 App 內入口。
4. 依同一份實際資料流填寫 Play Data safety，特別檢查自選模型與 MCP、語音、附件、本機 HTTP 及第三方 SDK；政策草稿不等於 Console 答案。
