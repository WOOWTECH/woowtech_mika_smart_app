第六版修正個人帳號中繼連線設定，避免已配對個人通道卻複製到共用 `/mcp` 網址。

- 新配對及既有配對透過 `/device/info` 取得並加密保存所屬通道網址；既有使用者開啟遠端設定頁即可取得，無須重新配對。
- 顯示閘道、個人／共用通道及電腦端 MCP／CLI API 網址。未取得驗證網址時停用複製，並提供更新狀態與錯誤說明。
- 複製 MCP 設定使用手機 MCP 存取權杖；不會複製配對裝置憑證。
- CLI 支援個人 `/r/<通道>/api/v1` 路徑；更換帳號時清除舊端點，避免延遲回應覆寫。
- 舊伺服器未支援查詢、網路中斷或限流不會自動解除配對；既有 WebSocket 協定保持不變。

查詢網址成功不代表 CLI/MCP 已連線，仍需在電腦端驗證。每支手機仍保留一份目前配對，並非同時連接多個帳號。網站需支援 App 整合契約 v1。Play Protect 側載攔截不在此次修正範圍。
