# 渥屋助理 0.1.37-woow.27

- 修正 woow.26 的「回到原本的機器人頁面」：在機器人頁面按 Home 後很快又點桌面圖示，原本會回到歷史頁，現在會回到那個機器人頁面；App 被系統回收後重新打開，也不會再疊出兩個服務頁。
- 新增 GitHub 上的 Android 模擬器裝置測試（Android 15、16），之後改到 woowtechbot 的程式都會自動在模擬器上實測。

## 驗證範圍

GitHub 模擬器（Android 15／WebView 124、Android 16／WebView 133）各 12 項裝置測試全過：
- 一台已登記的服務連不上時，其他服務的通知照常。
- 多台服務同時檢查。
- 通知顯示機器人名稱和內容摘要，鎖定畫面用一般文字。
- 從桌面圖示回到離開時的機器人頁面；自己按返回關掉的不會回去；已移除的服務不會被打開。
- 各服務的登入資料互相隔離。

另外 CI 的建置、單元測試和開機冒煙測試也全部通過。

## 已知限制

- 真正由伺服器送出、經 Google 推播送到手機的通知，模擬器測不到。這一段要用已配對的實體手機測。owner 的 Pixel 7 加入 Podman 站後還沒收到推播，原因待 Podman 後端查。
- 配對 QR 的掃描只用單元測試驗證，沒有在相機上實測。
- App 沒在執行時點通知，過渡頁出現前會先閃約 1 秒歷史頁。
- 畫面右側的懸浮膠囊可能蓋住列尾的「…」，點它下方一點即可。
- woow.21 曾在 App 內下載後被 Google Play 安全防護擋下安裝，原因還沒確認解決；不建議繞過安全防護。
