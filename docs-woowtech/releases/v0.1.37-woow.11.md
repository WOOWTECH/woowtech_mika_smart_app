# 渥屋助理 0.1.37-woow.11

這版加入對話文件產生與交付功能。

- 可要求助理將明確的報告內容產生為 HTML、PDF，或將指定的單一表格輸出為 CSV，並在對話中提供附件。
- 附件支援預覽、透過 Android 系統另存，以及開啟外部分享面板。取消操作不會回報為已儲存；開啟分享面板也不代表對方已收到。
- PDF 支援繁體中文、段落及表格跨頁；CSV 處理引號、逗號、換行，並防護可能被試算表視為公式的文字。HTML 使用靜態內容與受限制的預覽。
- 修正文件預覽操作的定位，讓 HTML、PDF、CSV 的另存與分享按鈕可穩定操作。

共用文件邏輯、Android 模擬器及 POCO 的對話產檔、預覽、另存與檔案分享已驗證。PDF 尚未嵌入中文字型，其他閱讀器仍可能依其字型環境顯示不同；CSV 的日期及前導零也可能被試算表自行轉換。此版不包含 Word、Excel 或公開網站託管。

沿用渥屋助理正式套件名稱與簽章。可在 App 的關於頁檢查更新，下載後依 Android 提示確認覆蓋安裝；既有資料會保留。這不是 App 關閉時的即時推播或靜默安裝。
