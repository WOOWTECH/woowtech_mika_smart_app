# 渥屋助理 0.1.37-woow.28

- woowtechbot 服務裡的檔案現在都能下載，包括圖片、影片、音訊、PDF、Word、Excel、HTML、ZIP 等。對話裡工作資料夾檔案旁的下載鈕，也就是網頁自己產生的檔案，原本會顯示「無法儲存此下載」，現在可以正常下載。
- 檔案直接存進手機的「下載」資料夾，不必再選位置。服務頁上方會顯示下載進度，可以取消；完成後顯示「已下載到「下載」資料夾：檔名」，按「開啟」就會用對應的 App 打開。
- 檔名優先用網頁指定的名稱，中文檔名也可以；檔案類型依副檔名判斷。服務把下載轉到雲端儲存時也能下載，而且不會把服務的登入資訊送給雲端儲存。
- 最近一分鐘內沒碰過畫面的下載會被擋下，避免網頁自己下載檔案。單一檔案上限 2 GB。
- 下載失敗時只顯示原因和「知道了」，不會再出現那個其實會重新載入網頁的「重試」。

## 驗證範圍

在 GitHub 上用兩台 Android 模擬器測試：Android 15（WebView 124）和 Android 16（WebView 133），各 18 項裝置測試全部通過。其中的端到端下載測試，是用真的服務頁打開下載測試頁，再一一觸發各種下載方式。每個檔案都以正確的檔名和類型存進「下載」資料夾，內容逐位元組相同。測到的下載方式：
- 網站本身的方式（xlsx、html、png、中文檔名的 pdf）
- 直接連結（pdf）
- 附件標頭（docx）
- 轉址（zip）
- data: 網址（csv）

另外也驗證了：沒點擊就觸發的下載會被擋下。單元測試和瀏覽器測試也都通過。

## 已知限制

- 還沒在真的 woowtechbot 站、實體手機上測過。
- 連到其他網站的檔案連結，仍會先問「在外部瀏覽器開啟連結？」，交給瀏覽器下載。
- 系統會把 .csv 的類型記成 text/comma-separated-values，開啟不受影響。
- 檔名很長的中文檔案（約 85 字以上）可能存不進去；使用 TalkBack 等無障礙服務時，下載可能被「需要點擊」的規則擋下。這兩項會在下一版修正。
- App 沒在執行時點通知，過渡頁前會先閃約 1 秒歷史頁。
- 畫面右側的懸浮膠囊可能蓋住列尾的「…」，點它下方一點即可。
- woow.21 曾在 App 內下載後被 Google Play 安全防護擋下安裝，原因還沒確認解決；不建議繞過安全防護。
