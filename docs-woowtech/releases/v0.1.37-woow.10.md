# 渥屋助理 0.1.37-woow.10

這版對齊外部 MCP 與個人技能的共用行為。

- MCP 工具、資源及提示都遵守每個伺服器的允許清單；任務執行期間撤銷或停用後，下一次工具呼叫會被拒絕。
- 技能結果評分會參考實際成功的工具呼叫，降低試用技能被誤停用的機會；模型連線失敗或沒有足夠證據時，維持未知結果。
- 長篇 MCP 結果保存在目前對話的工作區，可透過現有檔案讀取工具分段查看。

升級不會變更既有 MCP 允許清單；原本留空的設定仍代表不限制。兩版 App 的帳號、技能與 MCP 設定仍各自保存，不會自動同步。經 GitHub 安裝新版後，請依 Android 提示確認覆蓋安裝。
