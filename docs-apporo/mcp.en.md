# Apporo Assistant MCP

Enable computer access on the phone and use the address, port and token generated by **that Apporo Assistant installation**. Do not reuse a WOOWTECH token or another app's connection file.

For USB, first follow [the CLI setup](agent-quickstart.en.md). Configure a Streamable HTTP MCP connection at `http://127.0.0.1:8765/mcp` using the forwarded port and a private `Authorization: Bearer …` credential. Refresh tools and verify the request time on the phone.

Tool identifiers retain the shared Mika protocol names. Turning computer access off revokes its credential. Do not expose tokens, share the endpoint publicly or treat connection success as authorization to operate apps.
