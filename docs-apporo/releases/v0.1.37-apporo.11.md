# Apporo Assistant 0.1.37-apporo.11

Create and deliver documents directly from a conversation.

- Ask for a report as HTML or PDF, or export a selected single table as CSV. Generated files appear as conversation attachments.
- Preview attachments, save them through Android's document picker, or open the system share sheet. Cancelling a save does not report success; opening the share sheet does not claim that a recipient received the file.
- PDF generation supports Traditional Chinese and pagination of paragraphs and tables. CSV handles quotes, commas and line breaks, with protection against text being interpreted as spreadsheet formulas. HTML uses static content and a restricted preview.
- Document preview actions now have stable targets for saving and sharing HTML, PDF and CSV.

The shared document logic, Android emulator flows and POCO conversation generation, previews, saves and file sharing have been verified. PDF does not embed Chinese fonts, so rendering can vary in other readers. Spreadsheet apps may also reinterpret dates and leading zeros in CSV. Word, Excel and public website hosting are outside this release.

Apporo keeps its existing package, release certificate, English-first interface and independent update channel. Check for updates from the app's About page, download the APK and confirm the Android installation prompt to retain existing data. Updates are not silent installations or immediate notifications while the app is closed.
