## 發現與修正

1. **首次英文介面混入中文控制項**：原 APK 歡迎文字是英文，但 Back／Custom／Show 部分控制項取到系統繁中。`8670c03d` 在 Activity 附加 Context 時套用已選 locale。乾淨安裝重測 `retest/02-model-choice.xml`、`04-custom.xml` 已全為英文。
2. **透明標誌產生方形陰影**：歡迎頁沿用上游圖示陰影。改成可由品牌覆蓋的尺寸資源，Apporo 為0dp，上游與渥屋保持14dp。`retest/03-welcome-fixed.png` 已確認。
3. **英文記憶儲存失敗**：兩次真實模型任務被 `content_not_from_user` 拒絕。工具要求第三人稱改寫，來源檢查卻逐字核對英文，造成衝突。`5dd8a37c` 改為保留英文原句、關鍵詞也取自原話，沒有放寬來源檢查；新增測試同時驗證合法英文能儲存、額外名字仍被拒絕。修正版已完成儲存、跨新對話讀回與介面刪除：`retest/32-memory-save.json`、`33-memory-recall.json`、`34-memory-store.xml`、`35-memory-deleted.xml`。
4. **英文小錯字**：「a Apporo Assistant icon」改為「an Apporo Assistant icon」。最後另發現恢復說明的「a Apporo Assistant update」，已補上品牌字串覆蓋並通過來源檢查；這個最後的純文字修正尚未重新安裝APK驗證。
5. 提示詞刻意改動後，四個快照檢查失敗；`4fe83977` 同步可審查的工具定義、雜湊及大小快照，共用 Android／JVM／Python／Go CI、Apporo APK 與 WOOWTECH APK 檢查已全部通過。

## 尚需條件或補驗

- Apporo aiot／platform／smart 的真實帳號與測試主機尚未指定，不能證明場域、業務資料與電腦工作階段整合已完成。
- 公開 `Woow_apporo_ha_app` release 是舊 Apporo SmartHome alpha16，套件 `com.apporo.home.minimal.debug`；目前原始碼已改名為 `com.apporo.aiot`。下載及安裝成功，但直接啟動舊 release 無法解析 Activity，不能把它算成目前 Apporo aiot 通過。
- 已查到 Apporo smart 公開 release 目前這一筆只有桌面安裝檔，不能把它當 Android APK。
- 正式 Apporo 發行頻道與正式簽章尚未建置。測試簽章更新只代表開發測試，不等同正式線上更新驗收。
- 模擬器日誌的 beep=1 表示系統要求播放提示音；實際揚聲器音量、鎖屏、廠牌省電政策仍需實體手機。
- 執行中不用 uiautomator dump：它會短暫解除無障礙綁定。以截圖、錄影和系統日誌判斷穩定狀態。
