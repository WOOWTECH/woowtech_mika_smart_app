## Device limit and remaining distinction

Xiaomi's [POCO C85 FAQ](https://www.mi.com/pk/support/faq/details/KA-598270/) says this LCD phone does not support Always-on Display. It briefly reaches `Dozing/OFF`, then normally becomes `Asleep/OFF`. Therefore this run proves black-screen wake and stored-credential unlock on this phone; a **sustained AOD/Dozing panel** still requires another device that supports AOD. The first long trial's `wake_device` call happened after the phone had already woken, so it was excluded from the wake conclusion; the separate short trial is the evidence for wake.

The Apporo opener is deployed as an Odoo page, separate from the repository template. The Odoo view was updated and read back, then checked through the public URL and POCO Chrome. The Apporo LINE rich menu remains a separate integration and was not changed in this run. No new Android APK was required: the real `.9` build already had the tested remote behavior. These results cover the remote features above; they are not a claim that every unrelated WOOWTECH and Apporo feature has been retested.
