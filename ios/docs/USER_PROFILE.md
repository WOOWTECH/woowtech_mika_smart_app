# 個人檔案

2026-11-14 起依 Play 版調整：「記憶與資料」不再有個人檔案頁，個人檔案仍存在同一個加密學習檔，對話照常參考。`profile_edit` 不再顯示核對畫面，通過原話核對後直接儲存，聊天顯示「本次對話曾儲存個人檔案；可在資料頁用「全部清除」刪除。」。「全部清除」會刪除個人檔案及其修改紀錄。回覆進行中學習資料有變更（使用者清除或修改，或模型自己的工具修改），不再中止這次回覆。以下為先前紀錄。

行為來源為 Mika `0c172724f3f0c96f7345262588072f6e95db1138` 的 `core/memory/ProfileStore.kt` 與 `general/ProfileEdit.kt`。Swift 版本保留 20 條現用紀錄、每條 160 UTF-16 單位、單句及敏感資料檢查。取代或刪除需片段只在一條現用紀錄中出現一次；舊列改為 superseded，歷史不注入模型。這不是手機控制功能。

「記憶與資料 → 個人檔案」可新增、編輯及刪除，也可查看已替換／刪除歷史。資料沿用既有 AES-GCM 學習檔與本裝置 Keychain；先修改副本，再完成原子儲存，成功才更新畫面。v1／v2 舊檔沒有 profile 欄位時視為空檔案；欄位損毀或無法讀取時保留原檔、拒絕覆寫。

一般／MCP 對話在開始時取得個人檔案快照，置於目前要求之前的 user-role 參考資料。當輪要求優先，修改僅影響後續對話。「使用記憶」關閉時不加入快照，但保留資料。既有兩次確認的完整清除包含 profile 與歷史，並輪替學習金鑰；模型與 MCP 設定不受影響。

本機實測：核心 199 項斷言（含 CR/LF 新增、替換及解碼回歸）；實際 LearningStore／AES-GCM 保存、重開、寫入失敗回滾、舊檔遷移、開關與清除輪替共 58 項斷言。持久化測試只替換 KeyStore 與瀏覽器工具目錄，不存取個人 Keychain。相同持久化斷言亦接入 hosted XCTest。`1ea3d08` 的五個原生核心方法及一個 hosted 保存方法在三種模擬器全部通過；精確 iOS 17.0.1 原生核心亦通過。`dabe9bf` 的真實模型回憶／停用流程通過 1/1：兩次重開後分別回覆已存偏好及 UNKNOWN，停用不刪除資料。`1ea3d08` 介面測試曾有歷史列識別碼與逾時失敗，`faf7536` 拆為五個 Profile 案例，三種模擬器連同記憶流程共 32/39 通過、7 項失敗；本次修正保留關鍵字測試資料與原生輸入／點擊驗證，仍須重跑。詳見[驗證紀錄](VERIFICATION.md)。 `017976b` 的更新後真實模型介面重測也通過 1/1、零略過（98.688 秒）：原生輸入保存、重啟後精確回憶、關閉開關再重啟後回覆 UNKNOWN，原資料保留。見[本輪回憶證據](evidence/live-profile-recall-017976b.json)。

普通聊天新增 `profile_edit(op,text,match,quote)` 接線。`856e8ec` 的 iOS 26.2 原生／hosted 測試通過 193/193（其中這個 App 整合有 10 個方法）；本機真實模型也完成新增與加密重開；`f737665` 的真實模型 iOS 18.5 介面通過 1/1、零略過，實際提出 profile_edit、核對原話、點選核准，並在重啟後保留相同內容與 entry ID，見[實測證據](evidence/live-profile-tool-f737665.json)。這不取代其餘修改、刪除、拒絕與開關案例。主開關開啟且資料可用時，模型可提出一項新增、片段替換或刪除；App 只以本輪實際送出的使用者原話核對，不使用舊對話、助手文字、網站或工具結果授權。參數重複欄位、來源不符、無依據的具體值及不唯一的匹配會拒絕。工具核心本機六組共 97 項斷言通過。加入普通記憶工具後，Flow 五組測試通過；實際 App 邏輯搭配隔離加密檔案及固定模型回覆，Debug 468、Release 395 項斷言通過，涵蓋核准、拒絕、寫入失敗、取消、過期資料與保存後斷線。這些不是 iOS 介面或外網模型測試。

這版額外展示完整原話、目前內容及修改後內容，需點選核准才執行；這是與 Mika 原版提示詞授權方式不同的明確審閱步驟。個人檔案與普通記憶工具共用單輪最多一項修改、三次前景模型請求（包含最多一次格式修正及一次記憶搜尋），沿用一般聊天 90 秒整體期限。回答成功後原有的自動記憶整理另有一次背景模型請求，不包含在這三次內。儲存前重查主開關、資料 generation、profile revision 與期限，先原子保存再發布 receipt；當輪參考快照不變。已保存後若模型失敗，畫面保留保存紀錄，直到新對話，不將失敗回覆當成未儲存。

長對話保留畫面上的完整歷史；每次送出本輪全文、參考資料及最多 32 筆／64 KiB 內容範圍內的最近完整回合，並提示省略回合數。Flow 協議另外加入 system 指示。20 輪實際 App 邏輯測試保留 40 筆紀錄；超大的當輪輸入保留草稿且不呼叫模型。核心另有 48 項斷言通過。

MCP 分支也已接入獨立的本機個人檔案／記憶操作，共用原有 12 次模型決策與 180 秒期限。每輪僅允許一次本機修改，遠端呼叫仍另外核准；混合流程的原生 UI 與真實服務驗收另行記錄。獨立技能／瀏覽器工作流程尚未全面注入個人檔案。原版回答後自動整理的是記憶，不會自動整理個人檔案。普通記憶工具的新增、搜尋、編輯／刪除、待確認做法與撤銷詳見[記憶工具](MEMORY_TOOLS.md)。局部原生及本機真實模型結果不代表全部 Mika 工具或 iOS UI 全面通過。
